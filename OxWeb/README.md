# OxWeb

Flask + vanilla JS control panel skeleton with JWT cookie authentication, role-based access control and SQLite persistence.

## Run

    cp .env.example .env
    pip install -r Configurations/requirements.txt
    cd Backend
    python app.py

Open `http://127.0.0.1:5100`.

## Environment

- `OXWEB_SECRET_KEY` (required)
- `OXWEB_SUPERADMIN_PASSWORD` (required)
- `OXWEB_SUPERADMIN_USER` (default `admin`)
- `OXWEB_SUPERADMIN_EMAIL` (default `superadmin@oxweb.local`)
- `OXWEB_CORS_ORIGINS` (default `http://127.0.0.1:5100`)
- `OXWEB_HOST` (default `127.0.0.1`)
- `OXWEB_PORT` (default `5100`)
- `OXWEB_ENV` (`production` enables Secure cookies)

## Structure

    Backend/
        app.py              application, CORS, rate limiter, global API auth guard
        config.py           environment and paths
        auth.py             JWT creation, cookies, login_required, role_required
        users_store.py      users table, bcrypt hashing, lockout, super admin seed
        store.py            application database layer (targets example)
        web_results_store.py Whois/DNS report database and JSON importer
        helpers.py          JSON response helpers
        routes/             static_files, auth_routes, admin_routes, meta, targets
    HTML/                   index, login, admincpanel
    CSS/                    variables, layout, topbar, sidebar, buttons, modals, auth, views
    JS/                     state, utils, api, auth, views, nav, admincpanel

Whois/DNS reports generated by OxWebx can be uploaded from the Upload Results view.
They are stored in `upload/web_results.db` in the `whois_dns` table. Fixed summary
columns, per-check columns and per-finding columns are created during import, and
the Whois/DNS view reads the stored columns for rendering.

The Whois/DNS view includes a Reset action for operator-level users. It deletes
only rows from `whois_dns`, resets its autoincrement sequence, and runs SQLite
VACUUM to reclaim unused database pages.
    Configurations/         requirements and static assets
    data/                   SQLite database (created at startup)

## Roles

`viewer`, `analyst`, `operator`, `manager`, `user`, `admin`, `super_admin`

## Adding a feature

1. Add tables and queries to `Backend/store.py`.
2. Add a route module under `Backend/routes/` and import it in `Backend/app.py`.
3. Add methods to `JS/api.js`.
4. Add a `<section class="view" id="view-NAME">` and a `data-view="NAME"` nav item in `HTML/index.html`.
5. Register `Views.NAME = { load() {...} }` in `JS/views.js`.
